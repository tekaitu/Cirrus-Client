## Java runtime downloaded by the app

When the person clicks "Install Java 21", Cirrus Client downloads **Eclipse Temurin 21** (GPLv2 with the Classpath Exception) from Adoptium and unpacks it into its own data folder. Cirrus Client does not bundle or redistribute it. See https://adoptium.net for the license and notices.

## Logo and icons

The Cirrus Client logo, wordmark and icons are artwork supplied by the project owner (see `docs/BRANDING.md`). They do not copy Minecraft, Mojang or other launcher branding.

Two official third-party brand marks are used unchanged, only to identify the services the launcher connects to:

- **Microsoft logo** (`src/assets/brand/microsoft.svg`): Microsoft Corporation's four-square logo, from Microsoft via Wikimedia Commons (`File:Microsoft_logo.svg`). It is simple geometry in the public domain; the unused neutral background panel was removed so it sits on a dark surface. Microsoft is a trademark of Microsoft Corporation.
- **Minecraft logo** (`src/assets/brand/minecraft.svg`): Mojang Studios' Minecraft wordmark, from `github.com/Mojang/web-theme-bootstrap` via Wikimedia Commons (`File:Minecraft_Logo-en.svg`). Minecraft is a trademark of Mojang AB / Microsoft.
- **Player capes and skins** are downloaded from Mojang's own texture host only when a signed-in player has them, and are shown as-is. No Mojang artwork is bundled with Cirrus Client; the Cirrus Cloud cape texture is original artwork generated by `branding/make_cape.py`.
