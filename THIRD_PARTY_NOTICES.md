No third-party source code has been copied into this repository.

The project depends on open-source packages installed from npm and crates.io at build time (including Tauri, React, Vite, Vitest, Testing Library, jsdom, and the Rust crates `sysinfo`, `serde`, `serde_json`, `reqwest`, `sha2`, `zip` and, for tests, `tempfile`). They are licensed by their respective authors, mostly under MIT or Apache-2.0. The exact dependency set and license texts will be listed here once lockfiles are committed and a license report can be generated (for example with `cargo about` and a JavaScript license checker).

Any launcher library adopted later must have its license verified first and its required notices added here before release. See [docs/LIBRARY-EVALUATION.md](docs/LIBRARY-EVALUATION.md).

## Java runtime downloaded by the app

When the person clicks "Install Java 21", Limited FPS downloads **Eclipse Temurin 21** (GPLv2 with the Classpath Exception) from Adoptium and unpacks it into its own data folder. Limited FPS does not bundle or redistribute it. See https://adoptium.net for the license and notices.

## Logo and icons

The Limited FPS logo, wordmark and icons are original artwork generated by `branding/generate_assets.py` (geometric shapes drawn in code, no fonts or third-party artwork). They do not copy Minecraft, Mojang or other launcher branding.
