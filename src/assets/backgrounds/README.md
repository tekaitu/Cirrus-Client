# Your own backgrounds

Cirrus draws its own voxel-style landscapes, so it needs no pictures. To use your own screenshots
(only images you made or have the right to use), drop files here:

- `home.jpg` (or .png / .webp): the Home page
- `library.jpg`, `browse.jpg`, `night.jpg`: Versions/Mods/Modpacks, Browse, and Settings/Accounts
- `default.jpg`: used for any page that has no file of its own

A dark layer is laid over the picture automatically so text stays readable. Use a wide image
(at least 1920x1080) for a sharp result.
