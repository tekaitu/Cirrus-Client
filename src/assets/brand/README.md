# Brand icons

Official logos live here; the launcher uses them automatically (no code change needed).

| File | Used for |
| --- | --- |
| `discord.svg` | Every Discord button and link |
| `github.svg` | Every GitHub button and link |
| `microsoft.svg` | The "Sign in with Microsoft" button |
| `minecraft.svg` | The Minecraft: Java Edition wordmark in account views |

Get them from each company's own brand page (or Wikimedia Commons, which mirrors the official files).
`discord.svg` and `github.svg` are single-colour and are drawn in the current text colour; `microsoft.svg`
and `minecraft.svg` are the companies' own files and are shown as they are. The Minecraft wordmark is wide,
so it keeps its aspect ratio (`brand-icon-wordmark`) instead of being forced into a square. Until a file
exists, a neutral icon is shown.
