# Brand icons

Drop the **official** single-colour SVG logos here and the launcher uses them automatically
(no code change needed):

| File | Used for |
| --- | --- |
| `discord.svg` | Every Discord button and link |
| `github.svg` | Every GitHub button and link |

Get them from each company's own brand page. The icons are drawn in the current text colour, so a plain
black or white logo works in both the Dark and Light appearance. Until a file exists, a neutral icon is shown.
